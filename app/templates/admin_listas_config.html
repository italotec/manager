Como funciona a validação?
1. Um template é enviado para cada número via Meta Cloud API.
2. O webhook da Meta retorna o status de entrega.
3. Erro "Business eligibility payment issue" → número TEM WhatsApp.
4. Erro "Message undeliverable" → número NÃO TEM WhatsApp.
⚠ O Webhook Logging deve estar ativado para a validação funcionar.
